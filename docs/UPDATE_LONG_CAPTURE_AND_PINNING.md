# Long pages in one image, references where you need them

Mouse4 is built for the moment after a screenshot: the information still has to be used.

Long Capture follows a scrollable page and stitches the visible sections into one complete image. The result can be copied or saved locally, which makes it easier to share a complete guide, compare a long layout, or keep a record without a folder full of fragments.

When the reference should stay visible, Pin keeps it above the desktop. The pinned window can be dragged, zoomed, and closed independently. It is useful beside a design, a terminal, a support ticket, or a page you are trying to follow.

The workflow stays deliberately narrow:

- select the useful area;
- capture the page or the detail;
- annotate, copy, save, or pin;
- continue working in the source application.

The current demo shows the real capture, scrolling, pinning, and translation flow in one short video: [Mouse4 demo](https://johnwish1590.github.io/Mouse4/#demo).
