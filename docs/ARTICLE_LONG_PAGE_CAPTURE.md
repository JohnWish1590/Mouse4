# Long-page capture should preserve the argument, not just the pixels

Long guides and documentation are usually designed as continuous pages. Headings introduce steps, examples explain the steps, and the conclusion depends on what came before.

Breaking that page into unrelated screenshots loses the relationship between those parts. The reader has to guess where one image ends, where the next begins, and which heading belongs to which detail.

Mouse4 Long Capture keeps the selected region active while the page scrolls. The application follows the real page movement and stitches the result into one complete image. The finished capture can be copied, saved, annotated, or pinned above the desktop.

The workflow is deliberately short:

1. Select the useful page area.
2. Start Long Capture.
3. Scroll through the page naturally.
4. Confirm the complete result.

The result is useful for documentation, changelogs, dashboards, research notes, and support instructions where the order of the content carries meaning.
