# Selected-text translation that stays with the source

Most translation workflows make the user leave the page, paste text into another window, and then find the original context again. Mouse4 takes a shorter route.

1. Select the text you want to understand.
2. Press `Alt+1`.
3. Read the result in the panel beside the source selection.

The panel is intentionally small and quiet. Copy sits at the end of the translated text, while the top actions handle reading aloud, text size, transparency, settings, pinning, and closing. Hover help uses short labels so the controls remain discoverable without becoming another toolbar full of words.

The default direction is practical for mixed reading: foreign-language text goes to Simplified Chinese and Chinese text goes to English. The provider, service URL, model, and API key can be entered manually in the translation-only settings page. The credentials stay local to the Windows user profile.

The feature is useful for documentation, research, support tickets, product pages, and any place where translation should be available without covering the source.
