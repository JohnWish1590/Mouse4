# Mouse4 1.4.0: send the words you are already reading

Screenshots are useful when the layout matters. Sometimes the useful part is just a sentence, a label, or a paragraph on a webpage.

Mouse4 1.4.0 adds a browser text handoff for that smaller case. Select text in Chrome, open the context menu, and choose **Send to AI**. Chinese Chrome shows **发送到AI**. The selection goes to the same daily ChatGPT conversation used by screenshot handoff, so the workflow stays in one place.

The feature is intentionally narrow. It is available for selected webpage text in Chrome; it does not watch the clipboard, intercept `Ctrl+C`, or add a system-wide Windows context menu. Text from other desktop applications can still be handled with Mouse4's screenshot workflow.

The existing safeguards remain in place: Mouse4 checks Chat mode before sending, protects unrelated drafts, keeps uncertain deliveries from being silently resent, and isolates individual failures for later manual review. The Chrome extension interface remains bilingual, while the product name stays English.
