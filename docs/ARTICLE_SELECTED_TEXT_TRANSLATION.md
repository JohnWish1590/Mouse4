# Translate one sentence without leaving the source page

Full-page translation is often more than the moment requires. When a single sentence is enough, opening another window breaks reading flow and makes it harder to compare the source with the result.

Mouse4 uses a shorter path. Select a sentence in a supported Windows application and press `Alt+1`. The selected text is read from the source application, then the translation appears in a light floating panel beside the selection.

The panel keeps the actions needed for the next step close by: copy the result, read it aloud, change the reading size, change the panel transparency, pin it, open translation-only settings, or close it. Unpinned panels follow the current task and disappear when the user moves on; pinned panels remain available as a draggable reference.

The default direction is automatic: foreign-language text is translated to Simplified Chinese, and Chinese text is translated to English. The translation service can be configured from the compact translation settings page, where the provider, service URL, model, and API key are entered explicitly and stored locally.

The goal is not to replace the source page. It is to make one sentence understandable while the source remains visible.
