# Keep the useful part close: why Mouse4 starts with context

Most screenshot tools answer one question: “How do I save this image?”

Mouse4 starts with a different question: “How do I keep this useful detail available while I continue working?”

A clean region capture is only the first step. After the capture, the result can be copied to the clipboard, saved as a local PNG, marked with a rectangle or arrow, or pinned above the desktop. The reference stays close to the document, browser, or support thread that made it useful.

That small change in workflow matters when the screenshot is not the final deliverable. It may be a visual reference for a design decision, a short error message for a support reply, or a paragraph that needs to stay beside a note. Opening a large editor adds another place to manage. A small floating reference keeps the next action visible.

The same idea applies to translation. Select the sentence that needs attention, press `Alt+1`, and read the result in a light panel near the selection. The source page remains in view, so the translation supports the task instead of becoming a separate task.

Mouse4 is built for these small moments: capture the detail, keep the context, and return to the work.
