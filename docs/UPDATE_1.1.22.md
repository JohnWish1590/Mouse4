# Mouse4 v1.1.22: capture the detail, keep the context

Mouse4 started as a small screenshot utility. The latest release keeps that foundation and adds a second workflow for information that does not need to become an image: selected-text translation.

## What is new

Select text in a supported Windows application and press `Alt+1`. The result appears close to the selection in a light floating panel, so the source page remains visible. The panel can copy the result, read it aloud, change the reading size, adjust its transparency, open translation-only settings, stay pinned, or close.

The panel remembers the reading size and transparency choice. A normal panel closes when you move on to another desktop action; a pinned panel stays available and can be dragged as a reference.

The release also tightens the surrounding screenshot workflow: long scrolling pages remain one complete local image, captures stay clipboard-ready, and pinned references remain draggable and zoomable.

## Why this belongs in a screenshot utility

The useful unit is not always a picture. Sometimes it is a sentence, a label, or a paragraph that needs to be understood before the work can continue. Keeping translation next to the selected text avoids a second browser tab and preserves the original context.
