## Product Hunt description

Mouse4 is a small Windows utility for the moments when useful information should stay close. Capture a region, stitch a long scrolling page into one image, annotate it, copy or save it locally, and pin it above your desktop. Select text and press the shortcut to translate it in a readable floating panel with copy, read aloud, font size, transparency, pin, settings, and close controls.

No account is required and the license is a one-time $4.99 purchase after a 14-day trial.

## Product Hunt maker comment

I built Mouse4 around a simple interruption: I would capture something useful, then lose it behind the next window. The current release keeps the workflow small from start to finish:

- capture a clean region or a long scrolling page;
- annotate, copy, save, or pin the result;
- select text and translate it without leaving the source page;
- tune translation reading size and panel transparency without opening the full application settings.

The demo uses real Windows footage. I would especially value feedback on the long-page capture flow and the selected-text translation panel.

## New Reddit r/SideProject post: long-page capture

**Title:** I built a Windows long-page capture that keeps the whole reading context together

**Body:**

Long guides and documentation are designed as continuous pages, but ordinary screenshots break them into disconnected pieces. I added Long Capture to Mouse4 so you can select the useful area, scroll naturally, and finish with one complete image.

The result is copied to the clipboard and saved locally. You can also annotate it or pin it above the desktop while you continue working.

The current build also includes selected-text translation with `Alt+1`, a compact floating panel, remembered reading sizes, and four transparency levels.

Demo: https://johnwish1590.github.io/Mouse4/marketing/Mouse4-demo-English.mp4

Product page: https://johnwish1590.github.io/Mouse4/

## New Reddit r/SideProject post: selected-text translation

**Title:** Mouse4 now translates one selected sentence without leaving the source page

**Body:**

I wanted translation to stay inside the reading workflow. In Mouse4, select a sentence in a supported Windows application and press `Alt+1`. The result appears in a light panel near the selection, so the source remains visible.

The panel has copy, read aloud, reading size, transparency, pin, settings, and close controls. Foreign-language text defaults to Simplified Chinese; Chinese text defaults to English.

Demo: https://johnwish1590.github.io/Mouse4/marketing/Mouse4-demo-English.mp4

Product page: https://johnwish1590.github.io/Mouse4/

I am especially interested in feedback on the panel position and how much context people want around a selected sentence.
