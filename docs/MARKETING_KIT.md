## Product Hunt description

Mouse4 keeps useful information close to the work already on your screen. Capture a region, stitch a long scrolling page into one complete image, annotate it, copy or save it locally, and pin it above the desktop.

Version 1.4.0 adds a second path into the daily ChatGPT workflow: select text on a webpage in Chrome and choose **Send to AI**. The selection goes to the same daily Chat conversation used by screenshot handoff. Chinese Chrome shows **发送到AI**.

Mouse4 includes a 14-day trial and a $4.99 one-time lifetime license. No subscription and no account are required.

## Product Hunt maker comment

I built Mouse4 around a small interruption: useful information appears on screen, but the next step often requires opening another tool and losing the original context.

The current release keeps the workflow short:

- capture a clean region or a long scrolling page;
- annotate, copy, save, or pin the result;
- select text in a Windows application and translate it beside the source;
- select webpage text in Chrome and send it to the same daily ChatGPT conversation;
- keep individual delivery failures in manual review instead of stopping later screenshots.

The Chrome extension checks Chat mode before sending, protects unrelated drafts, and does not monitor the clipboard or `Ctrl+C`. The product is commercial closed-source software; the public repository contains product material and release assets, not application source.
