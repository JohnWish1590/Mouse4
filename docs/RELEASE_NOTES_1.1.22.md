## Mouse4 v1.1.22

Mouse4 v1.1.22 brings the current capture and selected-text translation workflow together in one Windows installer.

### Highlights

- Translation copy action is centered on the final translated line at every supported reading size.
- Pinned screenshots remain visible, draggable, and zoomable; this release includes the fix for the pin drawing crash.
- Translation panels support large, standard, and small reading sizes, four frosted transparency levels, read aloud, copy, pin, settings, and close.
- Unpinned translation panels close when you move on to another ordinary desktop action; pinned panels remain available.
- Long Capture stitches real scrolling pages into one clipboard-ready and locally saved image.

Windows Setup installer. Includes a 14-day trial. No account required.
